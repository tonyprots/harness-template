# Шелл без зависаний

**Перед первым вызовом незнакомого инструмента — `command -v <имя>`.**
Что установлено на машине, проверяется фактом, а не памятью.

## Неинтерактивный шелл

У агента stdin не терминал, и часть программ молча ждёт ввода.

- Закрывать stdin: `команда < /dev/null`.
- Пейджеры отключать: `git --no-pager log`, `git --no-pager diff`.
- Интерактив (`read`, `fzf`, подтверждения установщиков) без флага обхода
  не вызывать.
- Сетевым запросам — явный таймаут: `curl --max-time 30`, `timeout=` в
  Python. Оболочечного `timeout` на macOS по умолчанию нет.
- Долгую работу запускать фоном средствами агента, а не `sleep` рядом с ней.

## Частые причины ошибок

- **Цепочка через `&&` в диагностике.** Первый `grep` без совпадений рвёт
  цепочку. Соединять через `;`, поиску давать хвост `|| echo 'нет совпадений'`.
- **Путь по памяти.** Сначала `ls` или поиск, потом команда по найденному
  пути.
- **Правка файла скриптом через `replace`.** Молча не находит строку. Правка
  файла — инструментом редактирования агента, скрипты — для вычислений.
- **Деструктивное без предпросмотра.** Сначала команда без `-delete` /
  `rm`, глазами по списку, потом действие.

## Мелочи

- Пробелы в именах файлов: `find ... -print0 | xargs -0 ...`.
- `wc -c` считает байты, а кириллица в UTF-8 занимает два байта на символ.
  Для длины текста — `wc -m`.
- GitHub — через `gh` (`gh pr view`, `gh api`), а не через веб-страницы.
