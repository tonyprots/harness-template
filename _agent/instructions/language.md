# Язык

Общение с пользователем — на **русском**.

Все тексты для человека тоже на русском: документы, планы, README,
инструкции, ревью, описания PR и задач, changelog, отчёты.

Если скилл, шаблон или пример написан на английском, перед сохранением
результата переведите пользовательский текст и заголовки.

Английский остаётся там, где он технически нужен: код, команды, пути, имена
файлов, идентификаторы, поля API, ключи JSON и YAML, названия библиотек и
продуктов, дословные цитаты.

Перед сдачей проверьте, что в артефакте не остались английские служебные
заголовки и заготовки.
