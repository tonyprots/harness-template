# Git worktree

- Рабочие деревья Git живут в `.worktrees/` в корне проекта.
- Перед созданием проверить, что `.worktrees/` есть в `.gitignore`; если нет —
  добавить.
- Если у проекта уже есть своя конвенция — следовать ей.
- Worktree, ветка которого слита, а дерево чистое, удаляется
  (`git worktree remove`) в рамках завершения ветки.
