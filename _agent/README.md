# Слой _agent/

Инструкции, профиль, журнал и шаблоны для любого ИИ-агента в этом
воркспейсе. Главный контракт — `AGENTS.md` в корне; при
конфликте он важнее всего, что лежит здесь.

| Путь | Что это | Режим |
|---|---|---|
| `profile.md` | Кто пользователь, чем занимается, как с ним работать | Заполняется на онбординге, дальше по просьбе |
| `instructions/` | Обязательный свод: язык, поведение, инженерия, CLI, worktrees | Читать перед серьёзной работой |
| `memory/learnings.md` | Журнал фактов и решений, только дозапись | Читать в начале задачи, дописывать в конце сессии |
| `templates/` | Шаблоны `PROJECT.md`, брифов задачи и исследования, заметки памяти | Брать при старте проекта |
| `tools/rotate-learnings.py` | Ежемесячная ротация журнала в `06_archive/` | Запускать 1-го числа |

Инструкции — отправная точка, а не догма. Поменялось, как вы работаете, —
поправьте файл, и агент это подхватит.
