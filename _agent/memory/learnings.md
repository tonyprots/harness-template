# Журнал

Только дозапись. Формат: `- YYYY-MM-DD — факт, решение или предпочтение`.

Агенту: читать в начале серьёзной задачи, дописывать в конце сессии, если
узналось что-то долгоживущее.

## Жёсткие границы

- **Одна запись — одна строка, до 200 знаков.** Длиннее — это заметка:
  отдельный файл в `<проект>/.memory/`, а здесь строка-указатель.
- **Проектное — в `<проект>/.memory/`.** Проверка: «если проект закрыть,
  строка ещё нужна?» Нет — не сюда.
- **Статус не логировать** («выкачено», «ждём ответа»): ему место в
  `PROJECT.md`.
- **Ротация раз в месяц**: `python3 _agent/tools/rotate-learnings.py`
  уносит прошлые месяцы в `06_archive/`. Журнал читается целиком, поэтому
  не должен расти дольше месяца.
