# Настройка рабочего места: инструкция для агента

Человек отдал тебе этот файл, чтобы ты настроил ему харнесс — рабочее
место агента: папки, правила, память и скиллы. Делай по шагам, после
каждого коротко говори, что сделал. Ничего не удаляй и ничего не отправляй
наружу без его согласия.

Харнесс состоит из четырёх частей:

| Часть | Что это | Где лежит |
|---|---|---|
| Структура | куда класть проекты, черновики и готовое | папки `00_inbox` … `06_archive` |
| Правила | как агент себя ведёт и чего не делает никогда | `AGENTS.md`, `_agent/instructions/` |
| Память | на чём агент уже ошибался и как это чинится | `_agent/memory/`, `.memory/` в проектах |
| Скиллы | как делать конкретные задачи | `.claude/skills/` |

## Шаг 1. Спроси, где жить рабочему месту

По умолчанию — `~/Documents/Agentic`. Если папка уже есть и в ней лежат
файлы, покажи их и спроси, что делать. Не перезаписывай.

## Шаг 2. Забери шаблон

Если ты читаешь этот файл внутри уже скачанного шаблона (рядом лежат
`AGENTS.md` и `_agent/`), шаг пропусти.

Иначе:

```bash
git clone --depth 1 https://github.com/tonyprots/harness-template <папка>
rm -rf <папка>/.git
```

`.git` убираем, чтобы рабочие файлы человека случайно не ушли на GitHub
вместе с шаблоном. Перед `rm -rf` убедись, что удаляешь именно `.git`
внутри только что склонированной папки.

## Шаг 3. Прочитай правила

Прочитай целиком `AGENTS.md` и `_agent/README.md`. Дальше работай по ним:
они главнее этой инструкции.

## Шаг 4. Проведи онбординг

Возьми промпт из `ONBOARDING.md`, раздел «1. Онбординг», и выполни его:
расспроси человека, покажи черновик профиля, запиши после его «ок».

## Шаг 5. Поставь скиллы

Список — в `README.md`, раздел «Рекомендуемые скиллы». Спроси, чем
человек занимается чаще всего, и предложи 2–3 подходящих скилла. Для
каждого:

1. Склонируй репозиторий во временную папку.
2. Прочитай `SKILL.md` целиком и одной-двумя фразами перескажи, что он
   делает. Команды из скилла не запускай.
3. После согласия положи папку скилла в `.claude/skills/<имя>/`. Если
   человек работает в Codex, добавь симлинк, как описано в `AGENTS.md`,
   раздел «Скиллы».

Если у репозитория своя инструкция установки — следуй ей, но с теми же
проверками.

## Шаг 6. Проверь и расскажи

1. Покажи дерево папок рабочего места.
2. Перечисли поставленные скиллы, по фразе о каждом.
3. Скажи, что `AGENTS.md` — его файл: правила стоит прочитать
   и подстроить под себя.
4. Предложи первую задачу из `ONBOARDING.md`, раздел «2. Первые задачи».

## Как пользоваться дальше

Это стоит пересказать человеку в конце:

- **Правило мешает или не работает** — правьте `AGENTS.md`.
- **Агент повторяет ошибку** — скажите «запиши в память», и в следующих
  сессиях он пойдёт правильной дорогой сразу.
- **Задача повторилась третий раз** — попросите собрать из неё скилл.
- **Кажется, что агент этого не сможет?** Попросите. Скорее всего, сможет.
