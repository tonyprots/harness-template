# Харнесс: рабочее место ИИ-агента

Шаблон папки, в которой работает агент: Codex или Claude Code. Внутри
структура папок, свод правил для агента, память и шаблоны. Агент с первого
дня знает, куда класть файлы, что спрашивать, а что делать самому, и
помнит, на чём вы остановились.

## Что внутри

```text
00_inbox/       новые и неразобранные файлы
01_work/        рабочие проекты, по папке на проект
02_research/    исследования и база знаний
03_code/        код и скрипты
04_personal/    личное
05_outputs/     только финальные результаты
06_archive/     закрытое: сюда переносят вместо удаления
_agent/
  profile.md        кто вы и как с вами работать (заполняет онбординг)
  instructions/     язык, поведение агента, инженерия, шелл, worktree
  memory/           журнал learnings.md: одна строка до 200 знаков
  templates/        PROJECT.md, брифы задачи и исследования, заметка памяти
  tools/            ротация журнала
.claude/skills/     ваши скиллы
AGENTS.md           правила для агента (Claude Code 2.1.277+ и Codex)
ONBOARDING.md       промпты первого запуска
AGENT-SETUP.md      инструкция агенту: настроить всё одной командой
```

Каждый проект — папка с `PROJECT.md`: цель, контекст, решения, текущее
состояние. Черновики лежат в `drafts/` проекта, итог — в
`05_outputs/<проект>/`. Память проекта — в `<проект>/.memory/`, по одному
факту на файл.

## Установка

**Быстрый путь.** Поставьте агента (шаг 1), откройте его в любой папке и
скажите: «Прочитай github.com/tonyprots/harness-template/blob/main/AGENT-SETUP.md и настрой мне рабочее
место по нему». Агент сам заберёт шаблон, проведёт онбординг и поставит
скиллы. Ниже — то же самое вручную.

### 1. Поставить агента

Codex:

```bash
npm install -g @openai/codex
```

Или Claude Code:

```bash
npm install -g @anthropic-ai/claude-code
```

Нужна подписка: ChatGPT Plus или выше для Codex, Claude Pro или выше для
Claude Code. При первом запуске агент попросит войти в аккаунт.

### 2. Забрать шаблон

```bash
git clone --depth 1 https://github.com/tonyprots/harness-template ~/Documents/Agentic
```

Отвяжите папку от репозитория шаблона. В ней будут рабочие данные, и
случайный `git push` не должен унести их на GitHub:

```bash
rm -rf ~/Documents/Agentic/.git
```

### 3. Пройти онбординг

```bash
cd ~/Documents/Agentic && codex
```

Первым сообщением вставьте промпт из [ONBOARDING.md](ONBOARDING.md#1-онбординг).
Агент расспросит, кем вы работаете, чем заняты и что для вас важно, и
заполнит `_agent/profile.md` и раздел «О пользователе» в `AGENTS.md`.

### 4. Подключить свои сервисы (по желанию)

Агент дотягивается до почты, календаря, Notion, Google Drive и других
сервисов через коннекторы (MCP). Начните без них: сначала поработайте с
файлами в папке, а коннектор добавляйте, когда задача упрётся в сервис.
Подключённое запишите в `_agent/profile.md`.

### 5. Работать

Дайте агенту настоящую задачу из своей работы. Промпты для первых шагов
есть в [ONBOARDING.md](ONBOARDING.md#2-первые-задачи).

## Рекомендуемые скиллы

Скилл — папка с инструкцией `SKILL.md`, которую агент берёт сам, когда
задача подходит. Чтобы поставить, отдайте агенту ссылку: «Установи скилл
github.com/…». Агент прочитает его, перескажет и поставит.

| Зачем | Репозиторий |
|---|---|
| Продукт: для кого и зачем, PRD | github.com/zamesin/Next-Move-Theory-Canon-and-Skills |
| Архитектура и разработка | github.com/mattpocock/skills |
| UX: стили, палитры, шрифты | github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| UI: полировка интерфейсов | github.com/jakubkrehel/make-interfaces-feel-better |
| Тексты без следов нейросети | github.com/ilyautov/humanizer-ru |
| Редактура и корректура | github.com/beaverbeard/redkollegiya |
| Расшифровка аудио и видео | github.com/tonyprots/transcriber-skill |
| Ролики кодом | github.com/tonyprots/motion-film-skill |
| Презентации | github.com/tonyprots/html-deck-skill |

Начните с двух-трёх под свои задачи, остальные добавляйте по мере нужды.

## Как поддерживать

- Правила меняются в `AGENTS.md` и `_agent/instructions/`: это ваш
  харнесс, подстраивайте его под себя.
- Раз в месяц: `python3 _agent/tools/rotate-learnings.py`, чтобы журнал не
  разрастался.
- Задача повторилась в третий раз — попросите агента сделать из неё скилл в
  `.claude/skills/`.
